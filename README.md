## 📌 Sobre el proyecto

**Portafolio Personal** es un proyecto web creado para presentar mis trabajos, proyectos de programación, habilidades y mi progreso en el mundo de la tecnología.

La idea es construir un espacio digital donde cualquier persona pueda conocer lo que hago, explorar mis proyectos y descubrir las cosas que voy desarrollando.

Este proyecto forma parte de mi aprendizaje como desarrollador y representa mi interés por crear soluciones digitales, experimentar con nuevas ideas y mejorar mis habilidades.

## 🎯 Objetivos

- 💻 Mostrar mis proyectos y trabajos personales.
- 🚀 Compartir mis avances en programación.
- 🎨 Experimentar con diseños web modernos.
- 🧠 Aprender nuevas tecnologías y herramientas.
- 🌐 Crear una presencia personal en Internet.
- 📚 Documentar mi crecimiento como desarrollador.

## ✨ Características

- **Presentación personal:** un espacio para conocerme y descubrir mis intereses.
- **Proyectos:** una sección para mostrar mis trabajos y creaciones.
- **Diseño web:** una interfaz pensada para presentar el contenido de forma organizada.
- **Aprendizaje continuo:** un proyecto que puedo mejorar y ampliar con el tiempo.
