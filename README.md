## Sobre el proyecto

Este portafolio está hecho con HTML, CSS y JavaScript. Su página principal está en `web2/index.html` y reúne una presentación personal y una lista de proyectos públicos.

La sección de proyectos consulta la API REST pública de GitHub y muestra hasta seis repositorios propios, ordenados por estrellas y actividad reciente. No necesita token, inicio de sesión, servidor backend ni dependencias. Si GitHub no está disponible o se alcanza el límite de consultas, la página ofrece un enlace al perfil.

## Cómo verlo

Abrí `web2/index.html` desde un servidor web local o una publicación HTTPS y conectate a Internet para cargar la lista desde GitHub. Algunos navegadores limitan las solicitudes de red cuando se abre un archivo directamente con `file://`.

No hace falta instalar paquetes ni compilar el proyecto.
